Want the best translation? Add a free DeepL key

The extension works out of the box. For noticeably more natural translations, connect your own free DeepL API key — it takes two minutes and stays on your device.

  1. Create a free DeepL API account

    Open deepl.com/pro-api and sign up for DeepL API Free. A card is required to verify the account, but the free plan is never charged. free · 500,000 chars/mo

  2. Copy your authentication key

    In your DeepL account go to Account → API keys and copy the key. Free-plan keys end with :fx.

  3. Open the extension panel

    On a video page, open the Dual Subtitles panel and go to 2 · Translation → Translator keys / servers.

  4. Paste the key

    Paste it into the DeepL API key field. It is saved locally in your browser only.

  5. Pick DeepL and enjoy

    Set Translator to DeepL or leave Auto; DeepL is used first when a key is present. Done.
